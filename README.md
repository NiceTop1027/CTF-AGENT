# CTF Autopilot

여러 CTF에서 재사용하는 제목 기반 자동 풀이 시스템입니다.

## 작업 폴더 선택

작업 폴더 이름은 사용자가 정합니다. 공통 코드는 홈의 이 디렉터리에 있고,
문제·로그·라이트업은 선택한 대회 폴더에만 저장됩니다.

```bash
cd /home/s13w00/CTF/2026/my-event
ctf start
```

`ctf start`가 사이트 URL, 아이디, 비밀번호를 순서대로 물은 뒤 작업 폴더를
자동으로 준비합니다. 로그인 확인, 문제 목록·상세 분석, 첨부파일 수집, 쉬운
문제 우선순위 선정, Codex 병렬 풀이, 플래그·라이트업 기록까지 이어서 진행합니다.
workers 기본값은 3이므로 직접 입력할 필요가 없습니다.

전역 명령을 설치하면 어느 폴더에서든 다음처럼 실행할 수 있습니다.

```bash
ctf continue
```

현재 디렉터리를 작업공간으로 사용해 이어서 실행합니다.

중간에 `Ctrl-C`로 멈췄다가 이어서 하려면 다음처럼 실행합니다. 이미 끝난
문제는 건너뛰고 남은 문제만 계속하며 로그인·첨부파일 수집·초기 분석을
반복하지 않습니다.

```bash
ctf continue
```

URL과 아이디는 작업 폴더의 설정 파일에서 재사용하고, 비밀번호는 저장하지
않으므로 계속할 때 화면에 다시 입력합니다. 문제를 풀던 중 중단돼도 이미 수집한
문제·분석·라이트업은 유지하고 남은 작업부터 이어갑니다.

원하는 절대경로도 직접 사용할 수 있습니다.

```bash
ctf start /home/s13w00/CTF/2026/my-event
ctf continue /home/s13w00/CTF/2026/my-event
```

## 결과

- `data/runtime/live_status.json`: 실시간 제목별 상태
- `data/runtime/agent_activity.json`: 문제별 현재 Codex 단계·최근 공개 요약
- `data/runtime/agent_events.jsonl`: 터미널 명령·웹 검색·검증 이벤트 스트림
- `data/logs/ctf_continue.log`: 전체 실행 로그
- `writeups/<challenge-title>.md`: 제목별 라이트업
- `data/raw/challenges.json`: 포털 문제 원자료
- `data/raw/learned_patterns.json`: 성공·실패·기법 학습 기록

### Codex 모델

CTF 워커는 Codex CLI의 ChatGPT 로그인 세션을 사용하며, API 키를 사용하지
않습니다. 실행 때 로컬 Codex 모델 카탈로그에서 가장 높은 프로필을 선택하고
`--model`과 최대 추론 단계로 명시합니다. 현재 이 계정의 카탈로그에서는
`GPT-5.6-Sol / ultra`가 선택됩니다. 화면 상단 통계와 `모델` 이벤트에서 실제
선택값을 확인할 수 있습니다. 다른 계정을 쓸 때는 `CTF_CODEX_MODEL` 또는
`CTF_CODEX_REASONING` 환경 변수로 덮어쓸 수 있습니다.

재탐색은 이전 보고서를
`data/raw/agent_runs/challenge-<id>-attempt-<n>.jsonl`로 보관하고, 이전 후보
플래그를 새 후보에서 제외합니다. 이전 가설과 명령을 그대로 반복하지 않도록
회차별 다른 탐색 관점을 워커 프롬프트에 넣습니다.

### 안정화 동작

- 같은 문제의 메인 큐와 마우스 재탐색은 파일 잠금으로 동시에 실행되지 않습니다.
- 후보 미발견·일시적 워커 오류는 이번 세션에서 최대 2회 다른 전략으로 자동 재시도합니다.
- Codex 안전 정책 차단은 우회하지 않고 `모델 정책 차단`으로 표시합니다.
- 워커 타임아웃은 기본 15분이며 Codex가 만든 자식 프로세스까지 종료합니다.
- Discord·CAPTCHA·MFA·브라우저 로그인은 `수동 필요`로 분리하고 자동 재시도하지
  않습니다. 인스턴스/쿼터·HTTP 권한·네트워크·도구 오류는 각각 별도 상태로
  기록하며, 가능한 경우에만 자동 재시도합니다.
- UI 상단 `AI PROFILE`에서 모델과 추론 단계를 선택하고 `적용`을 누르면
  `data/runtime/codex_profile.json`에 저장됩니다. 이미 실행 중인 워커는 유지되고
  다음 워커부터 새 프로필을 사용합니다.
- 현재 실행 중인 프로세스에 코드를 덮어 적용하지 않으므로, 패치 후에는 한 번
  `Ctrl-C` 후 `ctf continue`를 실행해야 새 안정화 로직이 적용됩니다.
- 자동 제출은 제공하지 않습니다. 플래그는 화면·로그·라이트업에 기록됩니다.

문제 ID는 CTFd API 매칭에만 사용하고, 화면·라이트업·학습 JSON은 문제 제목을
우선 표시합니다.

대시보드 오른쪽 `LIVE AGENT STREAM`에는 내부 추론 원문 대신 안전한 공개 진행
요약, 실행 명령, 검색·검증 단계가 실시간으로 표시됩니다. `C` 또는 `플래그 복사`
버튼으로 제목별 플래그 목록을 클립보드에 보낼 수 있습니다.

## 중지

대시보드에서 `Ctrl-C` 또는 `Q`를 누르면 모니터, Codex 작업자, 재탐색·인스턴스
하위 프로세스를 함께 종료합니다. 문제를 다시 풀 때는 각 행의 `↻ 재탐색` 버튼을
마우스로 클릭하면 해당 제목만 즉시 다시 실행되고, 버튼이 `RUNNING…`으로 바뀝니다.
